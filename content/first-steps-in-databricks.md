My First Steps In Databricks
------------
I've fancied getting myself some databricks knowledge for quite a while now, and now that I've got myself moving on the task, I can see that it's easy to become overwhelmed with the breadth services available.  I initially found myself in that scenario, trying to learn everything at the one time.

Coming from an Azure background, which also contains a breadth of services, I should have known better.  I wouldn't recommend anyone starting out on Azure to grab a bit of everything and learn it all as quickly as possible, and I can see now that learing Databricks benefits from a more compartmentalised learning strategy.

Thankfully, after taking a bit of a breather and thinking about it logically, I can see a path through the Databricks jungle which will avoid most of the quicksand.

The obvious 1st step is the free self paced Databricks Fundamentals coarse and test.  The test is more of a knowledge check quiz than the horrific pressure testing environment of a proctored exam, but it's a good enough start for initiates like me.  The concepts and terminology in the fundamentals course is going to show up a lot, so it's more like "Databricks Essentials".

Following the essentials I went for "Get Started with Databricks Platform Administration"


An essential command is - 
"az databricks workspace delete --name xx --resource-group xx"
